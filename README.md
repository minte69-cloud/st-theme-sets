# Theme Sets — 캐릭터별 테마·상태창 자동 전환

SillyTavern 확장. 캐릭터(또는 그룹)마다 **테마 + 켤 정규식** 묶음("세트")을 지정해 두면,
채팅이 바뀔 때 알아서 갈아 끼워 줍니다.

## 쓰는 법

1. 확장 탭 → **Theme Sets** 를 엽니다.
2. **세트 추가** → 이름을 붙이고, 테마를 고르고, 그 세트에서 켤 정규식에 체크합니다.
3. 캐릭터 채팅을 연 상태에서 **쓸 세트** 를 고릅니다.
4. **기본 세트** 는 지정 안 한 캐릭터와 첫 화면에서 쓰입니다.

## 동작

- 어느 세트에든 체크된 정규식만 이 확장이 켜고 끕니다. 어디에도 체크 안 한 정규식은 건드리지 않습니다.
- 전역 정규식만 다룹니다. 캐릭터 전용(scoped)·프리셋 정규식은 그대로 둡니다.
- 테마를 바꾸면 SillyTavern이 글자 크기·채팅 폭도 테마 값으로 바꿉니다.
- 세트가 바뀌는 순간에는 채팅 영역을 잠깐 가렸다가 보여 줍니다(번쩍임 방지).
- 설정은 서버에 저장되어 모든 기기에서 같이 적용됩니다.

## 설치

SillyTavern → 확장 → **확장 설치** 에 이 저장소 주소를 넣습니다.
